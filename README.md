# DrMarioMania
 
This is a Dr. Mario fan game made with Godot and C#. More info is available [here](https://toadfangames.itch.io/dr-mario-mania).

To open the project, you'll need [Godot v4.3 .NET](https://godotengine.org/download/).
The main branch should be up to date with the latest build; the dev branch may contain work-in-progress features.

If you're just looking to play the game, you can download it [here](https://toadfangames.itch.io/dr-mario-mania).
